밴드 참여 현황 자동 집계

진주에덴교회 신앙 모임 밴드 · 비영리

안내

진주에덴교회 신앙 모임 밴드의 참여 현황 자동 집계를 소개하는 페이지입니다. 네이버 밴드 Open API로 교인의 참여 현황을 자동으로 집계하려고 합니다.

이 페이지의 주소는 Open API 신청서에 등록한 Redirect URI입니다. 담임목사가 밴드 화면에서 계정 연결에 동의하면 이 페이지로 돌아옵니다.

현재 운영 방식

  1. 진주에덴교회는 기도 · 성경통독 · 성경공부 모임을 비공개 밴드로 운영합니다. 모든 밴드의 리더는 담임목사입니다.
  2. 밴드마다 담임목사나 모임을 맡은 교인이 매일 그날의 글을 올립니다.
  3. 교인은 그 글에 댓글로 참여 기록을 남깁니다. 기도 모임은 기도한 시간을 적습니다(예: 「1시간 기도했습니다」). 성경통독 모임은 읽은 성경 범위를 적습니다(예: 「누가복음 8~9장 읽었습니다」).
  4. 담임목사나 모임을 맡은 교인이 이 댓글을 하나씩 읽고, 사람별 · 날짜별 참여 기록을 손으로 집계합니다.
  5. 집계한 사람이 현황을 밴드에 올립니다. 교인은 이 현황을 보고 서로 격려합니다.

밴드가 10개 정도이고 밴드마다 하루 댓글이 20~30개여서, 매일 댓글을 집계하는 데 많은 시간이 듭니다.

자동 집계 방식

지금 손으로 하는 댓글 집계와 현황 게시를 자동으로 처리합니다. 처리 순서는 다음과 같습니다.

  1. 매일 0시가 지나면 한 번 실행됩니다.
  2. 밴드 Open API로 밴드마다 최근 글과 그 글의 댓글을 조회합니다.
  3. 댓글에서 기도 시간이나 성경 읽음 여부를 확인하고, 사람별 · 날짜별로 집계합니다.
  4. 집계 결과로 현황 글을 작성합니다. 현황 글에는 전날 참여 인원, 최근 1주일 참여 여부, 이달 합계가 들어갑니다.
  5. 밴드 Open API로 현황 글을 담임목사 이름으로 게시합니다. 밴드마다 하루 한 개입니다.

집계를 맡은 사람은 더 이상 손으로 집계하지 않아도 됩니다. 교인은 지금처럼 댓글만 남기면 됩니다.

계정 연결

  • 모든 밴드의 리더인 담임목사 한 사람만 밴드 계정을 연결합니다. 연결은 밴드 Open API의 OAuth 절차로 한 번만 합니다.
  • 그래서 현황 글은 모든 밴드에서 담임목사 이름으로 게시됩니다.
  • 교인은 계정을 연결하지 않습니다.
  • 처음에는 2개 밴드(기도 모임 · 성경통독 모임)에서 시작하고, 이후 같은 교회의 신앙 모임 밴드 약 10곳으로 넓힐 예정입니다.

사용 API

API용도호출 횟수
글 목록 조회최근 며칠의 글을 찾습니다.밴드마다 하루 1번

밴드 Open API만 사용합니다. 브라우저 자동화나 매크로는 사용하지 않습니다.

운영 원칙

  • 광고 · 홍보 · 영리 목적이 없습니다.
  • 현황 글을 게시할 때 알림(푸시)을 보내지 않습니다.
  • 댓글은 참여 집계에만 사용합니다. 교인의 이름과 댓글을 밴드 밖에 공개하거나 다른 곳에 넘기지 않습니다.
  • 담임목사가 연결을 해제하면 자동 집계를 멈춥니다.
