# 진주에덴교회 밴드 참여 현황 자동 집계

진주에덴교회(https://www.jinjueden.com/) 신앙 모임 밴드의 참여 현황 도구입니다. 비영리입니다.

- 교인은 매일 밴드 글에 댓글로 참여를 남깁니다(기도 · 성경통독 · 성경공부).
- 자동 집계는 하루 한 번 **BAND Open API**로 댓글을 읽어 셉니다.
- 그 결과를 리더(담임목사) 이름으로 글자 현황 글 하나로 올립니다.

## 쓰는 Open API

| API | 언제 | 횟수 |
|---|---|---|
| 글 목록 조회 `GET /v2/band/posts` | 매일 0시 넘어 | 밴드마다 하루 1번 |
| 댓글 목록 조회 `GET /v2/band/post/comments` | 같은 때 | 최근 며칠 글마다 1번 |
| 글쓰기 `POST /v2.2/band/post/create` | 같은 때 | 밴드마다 하루 1번 · `do_push=false` |

- 연결: 리더 한 사람이 OAuth로 한 번 연결합니다. Redirect 페이지 = 이 저장소의 `index.html`(GitHub Pages).
- 범위: 2개 밴드로 시작 → 같은 교회 신앙 모임 밴드 약 10곳.
- 브라우저 자동화 · 매크로는 쓰지 않습니다.

## 개인정보

- 댓글은 참여 수를 세는 데에만 씁니다.
- 교인 이름 · 댓글 · 셈 결과는 이 공개 저장소에 두지 않습니다.
- 토큰과 Client Secret은 GitHub 비밀값에만 둡니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `daily.py` | 매일 한 번 실행합니다. 밴드마다 글과 댓글을 조회하고, 집계하고, 현황 글을 게시합니다. |
| `band_api.py` | 밴드 Open API 호출(글 목록 · 댓글 목록 · 글쓰기). 표준 라이브러리만 사용합니다. |
| `tally.py` · `parse.py` | 댓글에서 기도 시간 · 성경 읽음을 읽어 사람별 · 날짜별로 집계합니다. |
| `report.py` | 현황 글을 만듭니다(최근 1주일 점 · 이달 합계). |
| `get_token.py` | 리더 계정을 한 번 연결해서 토큰을 받습니다. |
| `index.html` | 소개 페이지 겸 Redirect URI 페이지입니다. |

밴드 설정(`config.json`)과 토큰은 이 저장소에 두지 않습니다.

## 고치기 · 명단

- 리더는 리더만 있는 비공개 관리 밴드의 지시 글에 댓글로 고칩니다: `수정 10/25 이름 2` · `이름 밴드이름 = 표이름` · `넣기 이름` · `빼기 이름`. 리더 · 공동리더 댓글만 반영합니다.
- 표에 나오는 사람 = 지난달 참여자 + 이달 댓글을 단 사람 + `넣기` − `빼기`.
- 매달 1일 글(지난달 정리)에는 지난달 기록이 있는 사람만 나옵니다. 기록이 없는 사람은 표에서 빠지고, 다시 댓글을 달면 돌아옵니다.

## 상태

Open API 발급 심사를 기다립니다(2026-11-20 신청). 집계와 현황 글은 지난 기록으로 시험했습니다. API 호출은 승인 뒤에 시험합니다.

## 자체 확인

```
python3 parse.py     # 댓글 읽기 시험

```
